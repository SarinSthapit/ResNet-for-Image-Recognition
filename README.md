# Deep Residual Learning for Image Recognition

For this project, a study of residual learning architectures for image classification was performed using the CIFAR-10 dataset, which involved analysing the degradation problem in deep neural networks and the effectiveness of skip connections in resolving optimization challenges. Through six structured tasks and five experiments, the study compared residual networks against plain networks across depths ranging from 20 to 56 layers, while evaluating design choices including projection methods and multi-layer skip connections. The obtained results showed severe performance degradation in plain networks, with 56-layer models underperforming 20-layer versions by 6.01 percentage points, while residual networks showed consistent improvement with depth, achieving 90.65% test accuracy at 56 layers. Rigorous statistical validation through five-fold cross-validation yielded a mean accuracy of 86.57% with 0.36% standard deviation, while bootstrap analysis provided a 95% confidence interval of [89.75%, 90.80%]. Hyperparameter optimization identified an optimized ResNet-32 achieving 91.16% test accuracy. The final results validate the residual learning principles for architectural design decisions in deep Convolutional Neural Networks (CNNs).

**Keywords:** Residual Learning, CIFAR-10, Degradation Problem, Skip Connections, Convolutional Neural Networks (CNNs).
